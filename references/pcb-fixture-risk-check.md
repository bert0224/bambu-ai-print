# PCB 与带线束电子模块夹具审查

PCB 的名义长宽厚只描述裸板，不描述可装配对象。除非已有机械图纸，必须把板、器件、焊点、连接器、线束和操作空间分别建模为不同的包络体。

下文“确认区域”指具有用户实测/确认、机械图纸等可靠证据的允许接触区域；跳过人工审批不替代这些工程事实。概念人工确认已明确跳过且省略图像时，先编写核心结构说明，完成同等包络、接口和装拆路径审查，构建前再绑定该文件的实际哈希。

## 照片审查顺序

1. 固定坐标：指定哪条边为上、下、左、右，正面和背面保持同一观察方向。
2. 勾出裸板轮廓，记录板厚、圆角、缺口和安装孔；照片估计不能作为紧配合尺寸。
3. 勾出正反面最高器件、超出板边的刚性接口、焊点和线束出口。
4. 标出可能的天线、电极、触摸区、测试点、散热面和状态灯；功能不明时一律按禁触区处理并询问。
5. 标出可接触的裸板边或用户确认的机械禁布区，记录允许覆盖宽度和高度。
6. 画出装入、夹紧、解锁和取出路径，再叠加刚性突出物、线缆自然弯曲和手指/工具扫掠空间。

## 必问约束

- 夹具用于通电测试、展示、焊接、测量、老化还是运输？不同用途决定绝缘、散热、刚度和接口可达性。
- 哪些区域允许接触？能否压住正反面，还是只能接触板边？是否允许遮挡器件、丝印、LED 或测试点？
- 夹紧期间 PCB 是否通电、发热或有射频/触摸功能？普通塑料和导电/碳纤维耗材都不能默认视为电气或射频安全。
- 所有线缆从哪里伸出，是否会插拔或持续拉拽？需要提供接头本体尺寸、插拔方向、线束自然弯曲空间和最大预期拉力。
- PCB 是否有多个版本或批次尺寸差异？批量夹具优先考虑浮动夹爪、软接触垫或可更换适配块。
- 允许哪些非打印件：螺丝、弹簧、磁铁、橡胶脚、泡棉或热熔螺母？没有规格时不能把它们画成可直接采购的已定零件。

## 夹持风险

- 优先在用户确认的裸板边或机械禁布区承力，避免直接压在焊点、0402 等小器件、连接器壳体或未知铜箔区域。
- 两侧夹爪应尽量对称传力，避免把 PCB 当悬臂弯曲；对薄板或高器件板，限制夹爪行程比仅依赖弹性手感更可靠。
- 夹持面应去锐边并控制接触面积。柔性垫会降低划伤风险，但其压缩量、老化和粘接方式也进入公差链。
- 频繁拆装时检查卡扣疲劳、层间方向和误操作；长期夹持时检查材料蠕变和夹紧力衰减。
- 夹具用于通电板时，接触材料、紧固件和底座不得无意跨接焊盘；ESD 控制应按现场流程验证，普通 FDM 塑料不能自动视为合格的 ESD 工装。

## 稳定性风险

- 静态站立只是第一步。把插拔力、线缆侧拉、线束自重和桌面摩擦纳入倾覆/滑移检查。
- 底座加宽、降低支撑高度、将 PCB 投影放入支撑范围、增加橡胶脚或机械固定是不同层级的措施；不能只凭“底面积看起来大”判定稳定。
- 如果用户需要单手插拔接口，必须把最不利插拔方向作为载荷工况；没有实测力时标为待验证，不虚构数值。

## 接口和装配路径回归案例

### 失败模式：底部插槽式夹具

场景：PCB 名义外形可进入底座槽，但 PCB 下边有超出板框的刚性 USB/JST 接口或已接线插头。

错误检查：只在最终竖直位置给接口留了空洞，或只验证裸板厚度能进入槽。

真实失败：PCB 必须沿竖直槽向下移动，接口或线束在途中先撞到底座；即使最终位置的空洞足够大，也没有可达的装入路径。

门禁：

- 将装配动作建成连续扫掠体，而不是只比较起点和终点。
- 若突出物不能穿过槽，改为张开后放入、侧向夹持、前后合模、可拆夹爪或其他开放路径。
- 提供概念图时必须显示连接器和线束，并用箭头展示完整装入与取出动作；合法省略图像时，核心结构说明仍须明确这些包络及运动路径。
- 在用户确认允许夹持区前，不得假设“中部任意位置都能夹”。中部也可能有器件、走线、天线或测试点。

### 本案例应加入回归断言

对任何带板边突出物的 PCB 夹具，概念审查必须回答：

1. 突出物是否需要穿过闭合槽或狭窄开口？
2. 夹具打开时的净开口是否覆盖完整对象包络，而不只是裸板厚度？
3. 线缆在装入、工作和取出三个阶段是否都有自然弯曲空间？
4. 夹持点是否位于用户确认区域，并避开正反面器件？
5. 最不利线缆拉力是否会使底座滑动或倾覆？

任一答案未知或为“是但未解决”时，风险状态保持 `open`，不得进入 CAD。

## 首件建议

PCB 夹具通常属于适配关键件。优先打印只包含夹爪、间隙和限位的局部试片，验证：

- 板厚和板边是否能顺畅放入；
- 夹紧后是否晃动、弯板或刮伤阻焊层；
- 正反面器件和焊点是否有余量；
- 解锁和取出是否无需拉扯线缆；
- 试片补偿是否与最终打印方向一致。

只有真实 PCB 试装后，才能把 `实物适配` 标记为通过。

# FDM 功能件工程风险门禁

本文件把常见失败模式变成可执行门禁。目标不是写一份形式化 FMEA，而是在投入 CAD 和完整打印前，尽早暴露会导致装不上、夹坏、变形、断裂、切片异常或误报完成的问题。

## 基本原则

- 用户描述的是目标，不等于完整工程输入。主动检查用户没有提到但会改变结构或材料选择的风险。
- 照片能证明“看到了什么”，通常不能证明精确尺寸、背面包络或运动路径。
- 静态不碰撞不等于能装入；必须检查对象、线束、工具和活动件的完整扫掠包络。
- CAD 尺寸正确不等于打印尺寸正确；关键配合需要同机器、同喷嘴、同材料、同方向和同类几何的校准证据。
- 切片成功不等于强度、稳定性或实物适配合格；完整件之前优先做低成本试片。

## 分阶段门禁

| 门禁 | 重点失败模式 | 最低证据 | 停止条件 |
|---|---|---|---|
| `G0 范围与安全` | 用途涉及人体承载、市电、压力、高温、食品或医疗，却按普通摆件处理 | 使用场景、失效后果、安全等级 | 缺少适用标准、认证材料或专业复核时，不给出“可安全使用”结论 |
| `G1 输入与测量` | 单张照片透视、遮挡、无比例；名义尺寸漏掉连接器、焊点、螺钉头或线束 | 多视角照片或图纸；关键尺寸的来源、工具和测量精度 | 影响配合或结构原理的尺寸仍是照片估计 |
| `G2 装配与接口` | 最终位置无碰撞，但装入途中卡住；接口可见却无法插拔；支撑或紧固件无法拆除 | 装入、锁止、解锁、取出动作；对象和工具扫掠包络；接触/禁触区 | 任一刚性突出物穿过封闭槽，或装拆路径未定义 |
| `G3 载荷与稳定性` | 夹紧力压坏对象；悬臂沿层间剥离；线缆拉动使底座倾覆或滑动；长期夹持发生蠕变 | 载荷方向和大致上限、持续时间、拆装次数、支撑多边形和抗滑方案 | 受力路径未知，或失败会损坏贵重对象且无保守设计/试验方案 |
| `G4 公差、材料与 FDM` | 插槽过紧/过松、首层象脚、收缩翘曲、薄壁消失、桥接下垂、支撑焊死、材料耐温不足 | 打印机、喷嘴、材料、方向、线宽/层高；关键配合试片计划 | 关键配合直接采用通用经验值且无校准计划；材料环境不相容 |
| `G5 CAD 与交换文件` | 非流形、零厚度、自交、多余实体、单位/缩放错误、网格过粗、版本错配 | 参数源、`DESIGN_ID`、实体有效性、包围盒、STEP 回读、STL/3MF 包检查 | 文件与确认方案或风险台账哈希不一致；关键几何检查失败 |
| `G6 切片` | 摆放方向削弱零件、薄特征被吞、首层变形侵入配合面、支撑困住、超出机器范围 | 真实 Bambu Studio、真实机器/喷嘴/材料配置、逐层预览 | 未真实切片却准备声称“可打印”；关键层出现断路、悬空或不可清理支撑 |
| `G7 首件` | 完整打印耗时后才发现配合、手感、稳定性或干涉错误 | 公差试片或局部样件的测量与试装；必要时完整件试装 | 适配关键却跳过首件；未试装却声称“实物适配” |

## 必须覆盖的风险类别

风险台账的 `coverage` 至少包含以下键：

- `evidence_measurement`：照片、图纸、实测数据及其置信度。
- `object_envelope`：主体、正反面凸起、线束自然弯曲、手指和工具空间。
- `assembly_motion`：装入、锁止、解锁、取出和误操作路径。
- `interfaces_keepouts`：允许接触面、禁触区、功能接口和观察窗口。
- `loads_stability`：静载、冲击、线缆拉力、重心、抗滑和倾覆。
- `tolerance_fit`：对象公差、测量误差、打印误差和装配余量的公差链。
- `fdm_process`：方向、壁/薄特征、悬垂、桥接、支撑、首层和翘曲。
- `material_environment`：温度、湿度、UV、化学品、蠕变、疲劳和阻燃需求。
- `cad_export`：实体、单位、坐标、版本、网格精度及文件回读。
- `slicer_first_article`：真实配置、分层检查、公差试片和实物验收计划。

风险配置含 `pcb` 时，另加：

- `pcb_contact`：板弯曲、阻焊层磨损、焊点/器件受压、夹持力和 ESD 操作。
- `electrical_rf_thermal`：天线/电极禁布、导电材料、散热面、爬电/绝缘和带电测试。

每一项只能是：

- `reviewed`：已评审，并给出证据或验证计划。
- `not_applicable`：确实不适用，并写明理由。

缺项、空字符串或只写“按常规处理”均不算完成。

风险台账还要保存已锁定的 `manufacturing_fingerprint`：打印机具体型号、喷嘴直径和材质、耗材完整名称、打印板、切片器及版本、工艺配置名称。任一项变化都视为制造输入变化，需要重新审查公差、薄壁、方向、支撑和试片证据。

## 风险项字段与状态

每个具体风险至少包含：

```json
{
  "id": "R-001",
  "category": "assembly_motion",
  "phase": "pre_cad",
  "severity": "critical",
  "status": "closed",
  "evidence_type": "user_confirmed",
  "failure_mode": "底部刚性接口在向下插入时撞到底座",
  "cause": "只检查最终位置，没有检查装配扫掠包络",
  "mitigation": "改为中部张开式夹持并保持底部开放",
  "verification": "在概念图中画出侧向装入动作并检查扫掠体",
  "evidence": "用户照片和确认记录"
}
```

允许阶段：`pre_concept`、`pre_cad`、`pre_export`、`pre_print`、`post_print`。

允许严重度：

- `critical`：可能造成安全事件、昂贵对象损坏，或结构原理根本不可用。
- `high`：大概率导致装不上、功能失效或完整打印报废。
- `medium`：影响寿命、表面、拆装体验或需要返工。
- `low`：不影响核心功能，容易补救。

允许状态：

- `closed`：已有证据证明约束被满足；必须填写 `evidence`。
- `accepted`：只允许 `medium` 或 `low`，必须填写 `acceptance_rationale`。
- `not_applicable`：必须填写 `rationale`。
- `planned`：后续阶段已有验证方案；不能用于 `pre_concept` 或 `pre_cad`。
- `open`：尚未解决。

`pre_concept` 和 `pre_cad` 的风险必须为 `closed`、合规的 `accepted` 或 `not_applicable`，否则构建脚本拒绝建模。`critical` 和 `high` 不得仅以“用户接受风险”关闭。`--skip-gate risk_review` 只跳过人工确认，不跳过本文件的任何风险覆盖、真实证据、专业验证及阻塞检查。

`evidence_type` 使用 `measured`、`drawing`、`photo_observed`、`user_confirmed`、`official_source`、`engineering_judgment` 或 `planned_test`。`critical`/`high` 风险不能只凭 `engineering_judgment` 或 `planned_test` 标为 `closed`。

## 常见但容易被忽略的设计痛点

### 照片与版本

- 正反面照片可能被旋转或镜像，必须定义同一坐标和基准边。
- 手指、贴纸和线束遮挡区域按未知处理，不根据相邻区域补画。
- 同名产品可能有 PCB 修订或外壳公差；一次性贴合设计应记录样件版本，批量使用优先可调或可更换接触块。

### 概念图的可信度

- 生成式效果图容易把孔位、厚度、夹爪连接和隐藏侧器件画错；它只能确认方案意图，不能作为尺寸或可制造性证据。
- 关键接口、禁触区、装配箭头和实测尺寸必须清晰标注；未知几何使用占位体，不允许为了画面整洁而删除。
- 概念图确认的是结构原理。最终 CAD 若改变接触位置、开合方式、零件数量或装配路径，必须返回概念阶段，更新受影响的确认或明确跳过记录。概念人工确认已明确跳过且未提供图像时，先编写核心结构说明并执行同等风险核对，构建前再绑定实际文件哈希；不省略接口、禁触区、运动路径或关键尺寸，也不要求文件首次生成前已有其哈希。

### 装配和维护

- 不只画“装好后”的样子，还要画张开量、插入角度、手指空间和拆卸动作。
- 螺丝、热熔螺母、磁铁或弹簧必须有真实规格、装配方向、工具空间和防脱方案。
- 支撑材料若位于窄槽、盲孔或配合面，可能无法彻底清除；优先改方向、分件或改变局部几何。

### 公差链

- 配合间隙应显式拆成对象尺寸偏差、测量误差、打印缩放/收缩、首层效应和期望松紧，不能只加一个“经验补偿”。
- 圆孔、外轮廓和 Z 向尺寸可能需要不同补偿；不得用统一缩放掩盖局部问题。
- 关键配合面尽量不要直接落在首层；必要时采用倒角、象脚补偿并做试片。

### 强度和寿命

- FDM 沿层间方向通常更易分离，打印方向应随主载荷确定，而不是只追求最少支撑。
- 夹臂、卡扣和薄铰链需检查根部圆角、最大应变、层向、循环次数和材料蠕变；长期受力不能只靠首次“掰得动”。
- 提高填充率不是唯一的加固方式；外壁数量、截面形状、圆角和打印方向常更关键，应在切片预览中一起核对。

### 切片和交付

- Bambu Studio 的线宽、薄壁、支撑、轮廓/孔补偿、象脚和收缩相关设置会改变最终结果，因此打印配置是制造输入，不是交付后的随意选项。
- 几何型 `.3mf` 只证明模型封装可读，不等于包含打印机、耗材、支撑和切片参数的 Bambu Studio 工程。
- 网格公差过大会损失小孔和圆角，过小会产生不必要的大文件；按最小功能特征选择并回读检查。
- 多零件装配要有零件清单、数量、材料、打印方向和装配关系；每个制造零件单独导出，参考对象和避让体不得进入打印 build。

## 首件策略

满足任一条件时，先输出试片而不是直接建议完整打印：

- 插槽、压配、卡扣、螺纹、轴孔或磁铁槽决定功能；
- 对象昂贵、易碎或带器件；
- 使用新材料、新喷嘴、新打印方向或未经验证的补偿；
- 完整件打印时间长，局部配合可独立验证；
- 用户要求批量或跨多台打印机复现。

试片必须保留与最终件相同的材料、喷嘴、关键特征方向、线宽和局部壁厚。记录设计值、打印后测量值、试装结果和最终补偿；只改补偿参数，不偷偷改名义对象尺寸。

## 依据与边界

- Bambu Studio 官方源码将孔/轮廓补偿、象脚、线宽、薄壁、支撑距离和悬垂阈值作为独立工艺参数，说明这些因素不能被一个通用公差代替：[Bambu Studio PrintConfig](https://github.com/bambulab/BambuStudio/blob/master/src/libslic3r/PrintConfig.hpp)。
- ISO/ASTM 52910 是通用增材制造设计问题识别框架，并不提供可直接套用的工艺/材料专用数值，因此本 skill 不内置“万能公差、壁厚或悬垂角”：[ISO/ASTM 52910](https://www.iso.org/standard/67289.html)。
- Bambu Lab 官方耗材指南给出的层间、耐热、吸湿和喷嘴要求随材料明显不同；材料选择必须结合环境与载荷，而不是默认 PLA：[Bambu Filament Guide](https://cdn1.bambulab.com/filament/FilamentGuide-EN-2.pdf)。
- Bambu Lab 官方材料兼容表按打印机、喷嘴、打印板及耗材分别给出条件，支持把它们绑定成制造指纹：[Bambu 材料兼容表](https://wiki.bambulab.com/en/general/filament-guide-material-table)。
- Prusa 官方 FFF 建模指南明确指出方向会影响结构完整性，悬垂需要支撑且模型需要实体/流形几何：[Modeling with 3D printing in mind](https://help.prusa3d.com/article/modeling-with-3d-printing-in-mind_164135)。
- CadQuery 官方文档说明 STL 的线性和角度容差会直接控制曲线离散质量与文件规模：[Importing and Exporting Files](https://cadquery.readthedocs.io/en/latest/importexport.html)。
- 3MF 核心规范定义了单位、正体积和流形网格等要求，但核心几何包本身不等同于特定厂商的完整打印作业：[3MF Core Specification](https://github.com/3MFConsortium/spec_core/blob/master/3MF%20Core%20Specification.md)。
- TI 的 PCB 天线资料说明塑料外壳等最终周边环境仍可能使天线失谐，因此只能按 keep-out 设计并在最终装配状态实测：[TI SWRA477](https://www.ti.com/lit/pdf/swra477)。
- ESD Association 将 ESD 作为包含接地、绝缘体风险评估、产品资格和符合性验证的系统控制问题；普通打印塑料不能单独证明 ESD 安全：[ANSI/ESD S20.20 概览](https://www.esda.org/news/an-overview-of-ansiesd-s20-20/)。

这些资料只能支持风险类型和检查方法，不能替代某台打印机、某卷材料或某个实物的测量与试装。
